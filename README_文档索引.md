## 三、文档间的依赖关系

```
游戏设计文档 v0.2 ──┬── 世界观与制度设定集（名词口径）
                    ├── 剧情与人物设定集（内容）
                    └── 序章关卡设计 ──┬── 白幡村布局 ── 数据表规范 ──┐
                                       └── 六空间图集                 │
                                                                     ↓
                                                          全关卡数据 CSV
                                                                     ↓
                                                          数据总表说明
数值验证报告 ←── sim_balance.py
制作规格 ←── 兵种表/线框/音频
美术规范 ←── Juhuo/Src/Game/Art/*.cs（代码即实现）
设定决策日志 ←── 记录以上所有拍板
```

**改任何一个数，先看决策日志第八节有没有把它列为"可疑"。**

1. **度量衡只用石 / 贯 / 匹 / 斤 / 亩**，不用"万石"以外的复合单位。
2. **六曹正式称"部"，口语称"曹"**；系统 UI 用"曹"。
