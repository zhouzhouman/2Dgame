`source` 写成 `拍:选项`，validator 的 E15 会查它指向的选项**真的存在**——指向不存在的选项，玩家永远拿不到那张卡。

## 一条 P0 裁定（重要）

**国策条数 = `min(3, 许过的条数)`，不是固定 3 条。**
十二拍里只有三拍能生成承诺，玩家全选第 0 项时一条都没有——写死"必须 3 条"会让他**永久卡在转段门口**。

## 玩法约定

- 立国策时 Esc 不能退（这是"不可逆的十分钟"）。
- 一条承诺都没许：第三页自动跳过，顶部闪「你这一趟没许下什么」。
- 报告页五行是文档原句（**不改写**）：国库空 / 粮价高 / 旧朝三路集结 / 宗室要供养 / 官员在等你发俸禄。
