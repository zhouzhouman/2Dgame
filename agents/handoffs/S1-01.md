# S1-01 · 双信任轴（官望 / 民望 / 疑心）

- 状态：DONE（规则 + 显示 + 一道门）
- 日期：2026-11-02
- 分工：D3 数据 / E1 规则 / E2 接线

## 数据

| 表 | 内容 |
|---|---|
| `trust.csv` | 9 条动作：行贿、送礼、办差、施粥、减价卖粮、治病、除霸、抗税、出卖同伴。每条带出处 |
| `routes.csv` | 两条攻城路线：`inside`（看官望）、`revolt`（看民望），阈值 60（**占位，待 D1 定**） |

两条轴按文档口径**互斥**：涨官望的多半掉民望，反之亦然；出卖同伴是「民望大跌、疑心大降」的脏按钮。

## 规则（Core）

- `TrustBook.Apply(id)` → 三轴各自钳在 0–100，返回**实际**增量与**意图**增量（`Intended*`）。
- `OpenRoutes()` / `IsOpen(id)` 按阈值判定；`Explain(delta)` 给 UI 一句话。

## 一条要记住的语义

**toast 显示意图增量，面板显示实际数值。**
理由：民望已经是 0 时，行贿仍要说「民望 −2（已见底）」——否则玩家看不见「跟官府走近会让百姓恨你」。
第一版用实际增量，结果民望整条消失，等于把设计里最重要的互斥藏了。

## 玩法（Game）

- `Tab` 开信任面板：三条横条 0–100 + 两条路线「可走 / 还差 N」。
- 信任变化时打 2 秒提示。
- **攻城选「间」需要官望达标**，不够时该选项灰着，选中提示「官望不够，城里没人给你开门」。

  接上时把 `Apply("action_id")` 挂进去即可。
