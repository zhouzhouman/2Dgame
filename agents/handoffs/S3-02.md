- 日期：2026-11-05

## 为什么做这张票

序章的骨架早就通了，但**十二拍里有五拍没有选项**（b02/b03/b08/b09/b10）。
玩家点完就过，没有任何决定——这不是缺系统，是缺"要不要做决定"。
一张序章如果一半的拍只是"看一段字、点继续"，它就不是游戏。

## 机制：效果进数据

`beats.csv` 新增可缺省列 `effects`：每个选项一组、`|` 分隔，组内 `;` 分原子效果。

```
"coin:+15;flag:book_sold|item:grain=4;min:-15;yi:+1;flag:village_raided"
```

支持：`coin` / `item:<id>=<n>` / `guan` / `min` / `yi` / `troops` / `flag`。
**组数与选项数不一致 → 当场抛错带行号**。这条护栏防的是错位——点「杀马」却扣了「卖刀」的钱。

## 两处旧规则被放宽

1. **"只有 choice 型才配选项"** → 取消。触发方式决定"什么时候来"，选项决定"要不要决定"，
   两件事不该互斥：b02 是敲门触发的抉择。
2. **敲门/搜查拍直接完成** → 有选项时先弹选择，确认后再完成。

## 效果失败的处理

囊满放不下时：**整组不落、这一拍不完成、把原因写出来**。
静默丢弃比报错更糟——玩家会以为选了却没生效。
