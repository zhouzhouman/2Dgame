## 五条工程约定（项目已有，必须遵守）

1. **交互是"八方向相邻"，不是圆形半径。** 斜角额外要求两个正交邻居至少一个站得下，避免隔墙角摸东西。
2. **出口必须在边界墙上开口。** 出口坐标同时写在 `tools/gen_prologue_data.py` 的 `EXITS` 与 `SceneConfig.cs`，两处必须一致。
3. **室内外用"从起点灌"判定**，不靠固定圈数。灌不到的就是室内。
4. **不改 `Content/*.csv`。** 数据由脚本生成，改了会被覆盖。
5. **分辨率 640×440，地块 16×16，角色 16×24，整数缩放。** 不做半像素位移。

## 写法规范

- Game 层不持有规则：不写 `if (taxRate > 0.1f)` 这种判断，调用 `Core`。
- 不硬编码文案/坐标/数值；文案走 `texts.csv`，坐标走 `points.csv`，数值走规则层。
- 输入统一走 InputMap；新增按键必须同时更新 `H` 操作说明。
- UI 用 Control 节点 + 容器布局，不手写绝对坐标堆叠。
- 每个新功能配一个调试参数（`--shot` / `--audit` / `--chain` / 新 flag），让 Q1 能无头验证。
- 单帧不做持续分配；列表用对象池或复用节点。

## 界面基调

- 全程"册子"隐喻：纸、账页、朱批。
- 资源栏是一条账绳，粮、钱、盐像筹码挂着。
- 民怨不用进度条，用颜色：地区墨色由浅到深。
- 奏报要像真奏折：竖排、朱批、有涂改痕迹；数字失真时"这笔墨不对劲"。
- 所有数字可点开"这笔钱从哪来"的溯源树。
