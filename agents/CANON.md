## 1 一句话

> 用三十天偷来一个王朝，用三十年证明你不是下一个旧朝。

2D 像素 · 正俯视 · 王朝模拟经营 + 叙事策略 · PC / Steam · 单人 · 22–27 小时。

## 2 不可动摇的十二条

1. **12% / 88%**：序章 30 天约 3 小时；正篇 30 年 360 回合约 20 小时。序章不许膨胀。
2. **只有一套数值**：序章一石粮和正篇一石粮是同一个东西，量级差 100 倍，不换皮不换档。
3. **序章首次对话不消耗刻**（D21，v1.1 修订）。不许改回去。
4. **度量衡只用 石 / 贯 / 匹 / 斤 / 亩**。除"万石"外不做复合单位。
5. **六曹正式称"部"，口语称"曹"，UI 用"曹"**。
6. **正俯视，全作统一**。基准 640×440，地块 16×16，角色 16×24，整数缩放。
7. **序章房子无顶**（能看见屋里），**正篇屋顶完整**（只能在门口交互）。这是叙事信号，不是美术偷懒。
8. **第二人称手记体**。所有叙述是"你"，不是"我"或"他"。
9. **真相是资源，且是唯一会反噬持有者的资源**。账册、空仓、奏报失真都服务于这一条。
10. **延迟后果必须落地**。序章第三十天做的事，正篇要有人找上门。
11. **结局是谥号 + 史评，不是一段 CG**。玩家不能辩解，因为每句都有出处。
12. **"变坏"必须是最省力、最快的路径**。任何系统如果让道德选择没有代价，就是设计错了。

## 3 名词表（写文本时必须用这套）

| 词 | 用法 | 不要写成 |
|---|---|---|
| 刻 | 序章时间单位，1 刻 ≈ 15 分钟 | 分钟、小时 |
| 官望 / 民望 | 两条独立信任轴，按地区 | 好感度、声望值 |
| 疑心 | 旧朝对你的警觉，按地区 | 通缉度（通缉是结果） |
| 保真度 | 你看到的数字有多真，0–100 | 准确度、可信度 |
| 奏报 | 六曹每月呈上的有立场的文本 | 报告、简报 |
| 誓约 | 序章承诺生成的卡，转段后变国策或债 | 任务、委托 |
| 内帑 | 皇帝私房钱，不受六曹审计 | 私房钱（UI 可用俗语解释一次） |
| 括户 | 回收隐户入籍 | 查户口 |
| 清丈 | 重新丈量田亩 | 土地改革 |
| 谥号 | 死后由史官给的评价 | 结局评级 |

**禁用现代词**：系统、数据、效率、机制、模块、触发、判定、数值、BUFF、DEBUFF。
写文本时若必须表达，用当时人能懂的话（"这笔账不对""下面的人瞒着"）。

## 8 绝对禁止

- 在 `Src/Core` 里 `using Godot`。
- 在 `Src/Game` 里写业务规则或硬编码数值。
- 在代码里写死文案、坐标、税率、兵种表。
- 用编辑器改 `Content/data/*.csv`。
- 升级 Godot / .NET / 改基准分辨率。
- 新增系统、加新面板、加新资源类型。
- 删测试、跳测试、改宽断言。
