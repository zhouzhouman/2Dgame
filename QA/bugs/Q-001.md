# Q-001 · `--audit` 跑完不退出，CI 里会挂死

- 严重度：P2（不影响玩法，影响自动化）
- 发现者：P0（2026-10-27 体检时实测）
- 状态：待修（归 S0-05 / E2）

## 现象

```bash
godot --headless --path Juhuo -- --audit
# 打印完 7 个空间的"够不着 0 件"之后，进程不退出，一直挂着
```

## 复现步骤

1. 在仓库根执行上面的命令（不加 `--quit`）。
2. 观察：7 行 `[自检]` 全部打印完，命令不返回。

## 期望

`--audit` / `--chain` / `--tutrun` 这类同步自检跑完后自行退出（`Main.cs` 里 `AuditReach()` 的注释写的就是"然后退出"，但函数末尾没有 `GetTree().Quit()`）。

## 实际

`AuditReach()`（`Juhuo/Src/Game/Main.cs:797`）只打印不退出；`--quit` 必须写在 `--` 之前才会生效。

## 临时绕过

```bash
godot --headless --path Juhuo --quit -- --audit
```

## 修复建议

在 `AuditReach()` 末尾补 `GetTree().Quit()`，但要放在 `--shot` 截图逻辑之后（`CaptureAndQuitAsync` 自己会退），避免把截图一起跳过——`TouchDemo()` 的注释已经踩过这个坑。

## 影响面

CI 的 headless 自检 job 会因此挂死；当前 CI 只跑 `dotnet test` 与 `tools/validate.py`，暂未受影响。
