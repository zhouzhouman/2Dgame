# Q-007 · Core 纯净性门禁只匹配两个字符串，漏判完全限定名的 Godot 引用

- 严重度：P2（当前漏不过 CI，但门禁语义与设计意图不符）
- 发现者：Q1（2026-10-28 CI 门禁负向测试）
- 状态：待修
- 依赖票：无
- owner：D3（`.github/**` 属冻结件，需 P0 签字，见 CANON §7）
- 证据报告：`QA/reports/2026-10-28-review.md` §5.3

## 现象

CI 的 `purity` job 用两条 grep 判定「`Src/Core` 里出现 Godot 引用就是事故」：

```yaml
if grep -rn "using Godot" Juhuo/Src/Core --include="*.cs"; then exit 1; fi
if grep -rn "GodotSharp" Juhuo/Src/Core --include="*.cs" --include="*.csproj"; then exit 1; fi
```

这两条**只覆盖 `using Godot`（导入语句）与 `GodotSharp`（程序集名）两种写法**。
用完全限定名（`Godot.Vector2`）引用 Godot 类型，**两条 grep 都匹配不到**。

## 复现步骤

1. 在 `Juhuo/Src/Core/` 下新建 `Probe.cs`：

   ```csharp
   namespace Juhuo.Core;
   public static class Probe
   {
       public static Godot.Vector2 Pos() => new Godot.Vector2(1, 2);
   }
   ```

2. 跑 purity 门禁：

   ```bash
   grep -rn "using Godot" Juhuo/Src/Core --include="*.cs"    # 无匹配，退出码 1
   grep -rn "GodotSharp" Juhuo/Src/Core --include="*.cs" --include="*.csproj"  # 无匹配，退出码 1
   ```

   → **job 仍然绿**。

3. 跑编译门禁：

   ```bash
   dotnet build Juhuo/Src/Core/Core.csproj --nologo
   ```

   → `error CS0246: 未能找到类型或命名空间名"Godot"`

## 期望

门禁应判定出「Core 引入了 Godot」。门禁自己的注释写的是：

> G0 门禁之三：Core 纯净性。`Src/Core` 里出现 Godot 引用就是事故，**机器校验，不靠自觉**。

现在的实现是「靠别人恰好不会写成完全限定名」。

## 实际

- grep 门禁判绿（漏判）。
- 实际拦住它的是**编译门禁的 CS0246**，不是纯净性门禁。
- 之所以没漏过 CI，是因为 `Core.csproj` 不引用 `GodotSharp` 程序集 —— 这是**副作用**，不是门禁的设计意图。

## 影响面

- **当前不会漏过 CI**：任何 Godot 类型引用都会让 `dotnet build` 失败。
- **但门禁形同虚设的风险是真实的**：一旦有人为了别的目的给 Core 加上 `GodotSharp` 程序集引用（或把某些源文件挪进 Core 又补上引用），grep 门禁**依然判绿**，而 `GodotSharp` 那条 grep 只查 `.csproj` 里的字符串——如果引用写成 `<Reference Include="GodotSharp"><HintPath>...</HintPath></Reference>`，字符串 `GodotSharp` 仍然会被命中；但如果通过 `Directory.Build.props` 统一加引用，**两条 grep 都不会命中**，且因为程序集已就位，**编译也不会失败** → 门禁彻底失效。
- 这条门禁的价值就是"机器校验，不靠自觉"。**用编译失败兜底，正是它要避免的"靠自觉"**（靠开发者恰好不写完全限定名）。

## 修复建议

改成判定**程序集引用**，而不是判定字符串：

1. 构建后检查 `Juhuo/Src/Core/bin/Debug/net8.0/Juhuo.Core.deps.json`，若出现 `GodotSharp` 库 → 失败。
2. 或检查 `Juhuo.Core.dll` 的程序集引用表（`System.Reflection.Metadata`）里有没有 `GodotSharp`。
3. grep 作为快速预筛保留，但**判定权交给程序集检查**。

验收：在 Core 里注入 `Godot.Vector2`（且 Core 能拿到 GodotSharp 引用）后，purity job 必须变红。

## 备注

- 顺带实测确认：**门禁当前不会误报**。全仓 11 处 `using Godot` 全部在 `Juhuo/Src/Game/`，`GodotSharp` 在全仓 `.cs`/`.csproj` 中 0 命中，`.gitattributes` 与 `.git/config` 里也没有这两个字符串。干净克隆实测两条 grep 均无匹配。
- 所以这是**覆盖不足**，不是**误伤**。两类问题要分开修。
